快速上手

三端部署命令一览 · 三端共享 gradio-app 的 Python 模块

Gradio-app（主力） python 3.10+ 
# 安装依赖并启动
cd gradio-app
pip install -r requirements.txt
python app.py
CLI 共用 gradio-app 依赖 
# 查看所有命令
python cli/main.py --help

# 单次执行 / 管道输入 / REPL
python cli/main.py text count "你好世界"
echo "你好" | python cli/main.py text count
python cli/main.py -i
Electron-app node 18+ · 部分功能需 python 
# 安装并启动开发模式
cd electron-app
npm install
npm run dev
